🚌 Simple Bus Reservation System

A simple console-based Bus Reservation System developed in Java using object-oriented programming principles.
This application allows users to simulate real-world bus ticket booking workflows including reservation and management of buses and passenger data.

🧾 Description

This is a Java console application that simulates a bus reservation system. The system allows users to view available buses, book tickets, and manage reservation records.
It is designed using core Java concepts and focuses on clean logic and data handling.

🚀 Features

✔ View list of available buses
✔ Book tickets through a menu-driven interface
✔ Check seat availability
✔ Manage reservation data
✔ Demonstrates OOP concepts like classes and objects

🛠️ Technologies Used

Java – Core programming language

VS Code / any Java IDE – Development environment

Object-Oriented Programming (OOP) – Implementation approach

Console Application – No GUI, text-based interface

📥 Installation & Running

Clone the repository:

git clone https://github.com/Rakeshsharma2025/Simple-BusReservation.git


Open in your Java IDE (VS Code / Eclipse / IntelliJ).

Compile the Java files:

javac src/*.java


Run the application:

java -cp src Main


Make sure you have Java JDK installed (version 8 or above).

🧠 How It Works

Upon running the program:

A menu appears prompting user actions.

Users can select:

Show available buses

Book a ticket

View reservation details

Exit

The system validates input and updates reservation data accordingly.
